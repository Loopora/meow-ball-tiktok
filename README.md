# Ball Escape Meow – TikTok Edition

Upload all five files into the **root** of your `ball-escape-meow` GitHub repository. GitHub Pages uses `main` and `/ (root)`.

**Sound:** Click **ENABLE MEOW** once. Browsers block automatic audio until a user gesture. After unlocking, the game plays the meow audio on every ball escape (overlapping sounds are possible when many balls escape at once).

**Controls:** Pause/Resume and Fullscreen inside the game, Restart and sound test outside, adjustable speed/gap/rotation/limit. Fullscreen is best used after enabling audio.
